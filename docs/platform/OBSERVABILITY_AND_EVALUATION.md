# Observability and Evaluation

## Observability

Canonical state:

- Runs;
- RunAttempts;
- RunSteps;
- logs;
- usage;
- cost;
- evaluation results.

External telemetry is exported, not canonical.

## Evaluations

Types may include:

- deterministic;
- schema/rules;
- datasets;
- LLM judge;
- human review.

OSS 1.0 may use evaluation gates before AgentVersion activation.
