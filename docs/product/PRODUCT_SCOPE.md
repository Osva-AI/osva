# Product Scope

## Included

### Agent lifecycle
Registry, versions, activation, pause/resume, deployment, ownership, health.

### Execution
Manual, API, schedule, webhook, event, batch, parent/child Runs.

### Runtime
Trusted TypeScript, Node SDK, Python SDK, HTTP, container, sandbox-compatible boundaries.

### Workflows
Sequential, branch, parallel, waits, events, approvals, human tasks, subworkflows, multi-agent composition.

### Models
ModelProfiles, provider adapters, structured output, routing, fallback, usage, cost.

### Tools
Tool registry, ToolVersions, ToolGrants, connectors, HTTP tools, MCP.

### Memory and knowledge
Run context, memory namespaces, KnowledgeSources, retrieval adapters.

### Observability
Runs, attempts, steps, logs, traces, usage, latency, failures, cost.

### Evaluation
Rules, datasets, LLM judges, human review, regression, quality gates.

### Security and policy
Authentication boundary, permissions, SecretReferences, approvals, budgets, policy hooks.

### Developer platform
REST API, SDKs, CLI, webhooks, adapter APIs.

### AI Office
OfficeWorkers, Teams, Roles, Goals, Assignments, HumanTasks.

## Not the core product

OSVA is not intended to become:

- a generic CRM;
- generic BI;
- generic ETL;
- a data warehouse;
- a vector database;
- a cloud IDE;
- a Kubernetes management product;
- a model-training platform.
