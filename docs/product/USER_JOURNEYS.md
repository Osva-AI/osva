# User Journeys

## Build an Agent
Create Agent → Create AgentVersion → Activate → Run → Inspect → Evaluate.

## Release a new version
Create AgentVersion → EvaluationSuite → compare → activate → rollback if needed.

## Automate work
Trigger → Workflow → Agents/Tools → Evaluation → Approval → result.

## Investigate failure
Run inspector → RunAttempt → RunSteps → logs/tool/model calls → root cause.

## Build an AI Office
Create OfficeWorker → assign Agent/Workflow → Team → Goal → Assignment → monitor results.
