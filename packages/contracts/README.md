# @osva-ai/contracts

Public OSVA contract types and Zod schemas consumed by SDKs, runtimes, and integrations.

Infrastructure adapter ports (M12.4.3+): `ArtifactBlobStore` and artifact storage configuration types are exported from the root entry for independently maintained adapter packages (for example osva-adapters).

Part of the [OSVA](https://github.com/Osva-AI/osva) monorepo (Apache-2.0).
