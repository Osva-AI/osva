# Code of Conduct

OSVA is intended to be a professional, constructive, and welcoming open-source project.

## Expected behavior

Participants should:

- communicate respectfully;
- critique ideas and code rather than people;
- provide actionable technical feedback;
- welcome contributors with different experience levels;
- respect privacy;
- avoid harassment, discrimination, threats, and personal attacks.

## Scope

This applies to OSVA repositories, issues, pull requests, discussions, and project-related community spaces.

## Enforcement

Maintainers may remove content or restrict participation when necessary to protect the project and community.

For conduct concerns, contact project maintainers privately through the OSVA GitHub organization until a dedicated community reporting address is published.
